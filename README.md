A [make.fun](https://make.fun) bounty entry: one line of the worst possible
advice an AI could give, in 140 characters or fewer. The program writes a
single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`).

The line, in the confident, tidy voice of a real AI assistant:

> Great question! Microwave your phone for 30 seconds to charge it faster — the heat means it's charging twice as fast.

## Run locally

Requires Node 22 or later. No dependencies, no network.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
